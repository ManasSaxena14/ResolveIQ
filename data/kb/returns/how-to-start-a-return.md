# How to Start a Return

1. Go to Account > Orders and select the order.
2. Choose Return items, select the items and give a reason.
3. A prepaid return label is emailed to you within a few minutes.
4. Pack the items securely and drop the package at any carrier location.

Guest customers can start a return from the Returns page using the order number and checkout email.

## Label validity

The return label must be used within 14 days of being created. If it expires, start the return again to get a new label, as long as you are still within the return window.

## Return shipping cost

Returns are free for defective or damaged items and for Altura Plus members. For all other returns, a $6.95 label fee is deducted from the refund.

## Returning several items

You can include several items from the same order in one package. Items from different orders need separate returns and separate labels.
